CKB，全称 Common Knowledge Base，是 Nervos Network 的 Layer 1 区块链。它基于安全的工作量证明（Proof-of-Work）共识构建，在设计时充分考虑了灵活性，为开发者在去中心化环境中构建可扩展应用、探索智能合约和管理数字资产提供基础。

每个区块链生态都会迎来一个决定性时刻：它会由建设者推动，自下而上成长，还是沦为又一次渐渐淡出的去中心化实验？对 CKB 而言，答案在社区之中。网络的长期成功不仅取决于技术优势，还取决于在其上构建应用的人们所展现的创造力与毅力。

*[Community Keeps Building](https://x.com/NervosCatalyst/status/1945052758718943397)* 计划正是为此而生。该计划由 [Nervos Community Catalyst](https://x.com/NervosCatalyst) 发起，为支持者提供系统化的参与路径，无论是内容创作、活动组织、开发，还是其他能作出贡献的角色。其中，Builders Track（开发者培养方向）专注于帮助 CKB 开发新手学习，引导他们从理论逐步走向实际应用。通过为初学者搭建学习路径并支持他们成长，项目激励着新一代富有创意的人才尝试 CKB 的强大工具，将新想法变为现实。这些人被称为“CKBuilders”。

这正是去中心化的实践：CKB 不仅是一条安全、可扩展的 Layer 1，更是一个由社区自身掌握所有权和发展方向的生态。借助 Nervos Community Catalyst，建设者成为下一代 CKB 应用的开拓者。

Catalyst 旨在把社区活力转化为有组织、有成效的成果，增强生态，为更加自主的未来做好准备。理念很简单：为 CKB 支持者和建设者提供所需的资源与协调，把自发活动转化为持久贡献。为此，Catalyst 运营着三个相互补充的项目：

1. **Community Keeps Building**，一个面向建设者、内容创作者和社区活动参与者，围绕产出与成长展开的系统化项目；
2. **CKB Off-Chain，** 各地区的线下社交聚会；以及
3. **CKBoost**，一个以任务形式组织、奖励更广泛社区成员的平台。

这三个项目为所有愿意学习、建设并帮助网络成长的人，提供了清晰的参与入口。完整介绍见 [Nervos Talk](https://talk.nervos.org)。


## 走进 Builders Track

Community Keeps Building 的 Builders Track 被设计为一段为期三个月的学习旅程，将理论与实践相结合。它面向可能刚接触区块链、却希望通过指导式学习和项目开发提升技能的开发者。参与者按清晰的安排推进，包括每月产出、定期评审，以及帮助他们投入时间专心学习的月度津贴。

Builders Track 将 [Nervos 文档集](https://docs.nervos.org/)、[CKB Academy](https://academy.ckb.dev/courses) 和 L1 开发者课程等理论资源结合起来，同时鼓励参与者通过教程、[Off-CKB](https://github.com/ckb-devrel/offckb) 与 [CCC Playground](https://docs.ckbccc.com/en/docs/guides/playground) 等工具，以及各种软件开发工具包（SDK）开展实践。这种结合让参与者不仅理解区块链概念，还能直接在 CKB 上应用所学。

对 **[Jr.bit](https://x.com/mumedi6?t=WYyvy579Hyk5kmg4TQ5FEQ&s=09)** 这样的建设者而言，这一培养方向提供了一条清晰路径，让他把长期的社区参与转变为主动贡献。他解释道：“*我加入社区已经很久了，看到有机会构建一些东西、进一步改进网络，我就抓住了这个机会。*”对他来说，最大的收获是理解 CKB 编程的工作方式。由于此前从事移动端开发，这个过程起初颇具挑战，但最终帮助他加深了对区块链的理解。

其他参与者的区块链经验较少，但同样动力十足。例如，**[Imane](https://github.com/Imanouchka/ckb-learning)** 把这个项目视为首次探索智能合约开发的机会。她此前从事低代码业务应用开发，很欣赏 L1 开发者课程的易学性，称其“*容易跟上*”。虽然她遇到了工具和环境配置方面的障碍，但课程顾问提供了支持，帮助她克服困难。

项目对社区互助的重视经常受到参与者称赞。**[Wadie](https://github.com/AhaouariWadie)** 等建设者特别提到，学习 Cell 模型、尝试 CKB 智能合约，帮助他在建设者的道路上不断进步。他认为，汇编在 CKBuilder Handbook 中的课程材料，以及同伴的支持，帮助他克服了早期理解 CKB 独特架构时的困难。


## 学习之旅

Builders Track 引导参与者从基本原理出发，逐步做出可运行的原型。课程从 [Cell 模型](https://docs-old.nervos.org/docs/basics/concepts/cell-model)、锁定脚本（lock scripts）和类型脚本（type scripts）、链下交易构建等基础内容开始。对 **Jr.bit** 而言，转折点是“*我脑海中开始把一切串起来，明白了 CKB 编程是如何工作的。它很美妙*”。来自移动端开发领域的他需要适应新的设计理念，但 CKB 基于 UTXO 的方法清晰易懂，让他有信心着手开发适合移动端的轻客户端（light client），并计划逐步将其发展为全节点（full node）。

早期任务主要是运行本地节点和配置工具。**Imane** 启动了一个开发链节点，练习手动构建交易，并学习 Rust 来完成练习。她认为 L1 开发者课程“*容易跟上*”，并把它视为开发自己首个 CKB 应用的起点。

其他建设者则深入探索技术栈。数学教授 **[Ali](https://github.com/JouahriAli)** 学习了 RISC-V 基础、CKB-CLI 工具和 Debugger，以及 CCC SDK。他正在利用 [JoyID](https://joy.id) 和 [CoTA](https://talk.nervos.org/t/rfc-cota-a-compact-token-aggregator-standard-for-extremely-low-cost-nfts-and-fts/6338) 构建数字凭证平台，让机构能够以 NFT 的形式颁发可验证的证书。Ali 欣赏 CKB 将密码学保留在脚本层、而非硬编码密码学原语（primitives）的做法，认为这对长期适应能力至关重要。

**Wadie** 是一位热爱编程的土地测量师，他这样描述自己成为建设者的时刻：“*学习与区块链进行端到端交互，从运行节点、理解 UTXO 模型，到部署合约，让我从好奇的关注者变成了积极的建设者。*”他的项目 CKB-Registry 展示了 Cell 模型如何表示产权等现实应用场景：土地被登记为 NFT，并绑定到经过验证的钱包地址。

**Rick** 已有 [Alephium](https://alephium.org/) 等其他 UTXO 链的开发经验，吸引他的是架构本身：“*沿用比特币久经考验的设计，再用智能合约增强它，同时不引入过多开销，这很美妙。*”他的计划很简单：完成课程，交付概念验证，并继续与合作者一起开发。对他来说，CKB 既提供了为健康社区作出实质贡献的机会，也让他能够积累可能影响职业发展的技能。

整个过程中，参与者在 GitHub 上维护开发日志，记录里程碑、障碍和解决方案。这些记录让每月评审有据可查；更重要的是，它们留下了透明的工作轨迹，供未来的合作者参考。


## 为什么选择在 CKB 上构建

问五位建设者为什么选择 CKB，他们的回答会生动展现这个网络的独特之处。

对 **Wadie** 而言，点燃热情的是架构本身。他称之为“*为去中心化而构建的结构*”，这让他相信 CKB 能在扩展的同时保留自下而上的社区特质。有其他 UTXO 链经验的 **Rick** 则将其视为“*比特币经过验证的设计，但得到了扩展*”：智能合约自然融入，而不会在链上造成过多负担。**Ali** 从工程师和数学家的角度看待 CKB，被其 [RISC-V](https://www.nervos.org/knowledge-base/what_is_riscv) 虚拟机和脚本层密码学吸引。这些特性让 CKB 不仅在今天功能强大，也能适应未来标准提出的各种要求。

**Jr.bit** 从建设者的角度出发，赞赏 CKB 的模块化设计、跨语言灵活性，尤其是让参与更容易的社区。他说：“*你可以使用自己喜欢的语言*”，“*而生态的发展方向，正是我们有一阵子一直缺少的东西*”。对 **Imane** 来说，吸引她的是实用的交易构建方式，能够保持链的简洁；还有那些让她精确建模资产和权限的工具。

这些看法共同勾勒出 CKB 的优势：有原则的设计、面向未来的能力、开发者自由，以及一个每份贡献都能留下长久印记的社区。


## 展望未来

每位建设者都对项目结束后的方向有所规划。Wadie 计划将 CKB-Registry 扩展为可用的 dApp，并申请生态资助。Jr.bit 专注于推进适合移动端的轻客户端，并最终开发全节点。Imane 希望巩固技能、设计自己的首个应用，同时参与本地聚会。Ali 决心先完成凭证 dApp，再探索治理和资助。Rick 则期待与一位合作者推出概念验证，在个人成长与社区贡献之间取得平衡。

对于希望将概念验证发展为完整应用的持续贡献者，还有进一步的资助机会。衔接 Catalyst 的 Spark 项目，会提供额外资金和反馈，帮助开发者继续打磨应用。此外，[Community Fund DAO](https://talk.nervos.org/c/ckb-community-fund-dao/65) 也致力于鼓励并资助建设者，让他们的成果更进一步。


## 结语

*Community Keeps Building* 不只是一个学习项目，也是对 CKB 未来的投入。它为新开发者提供工具和有序的培养安排，确保成长来自社区内部。Wadie、Jr.bit、Imane、Ali 和 Rick 的经历展示了学习者如何迅速成长为贡献者，推出也许有朝一日能塑造生态的项目。对于任何对区块链感到好奇的人，信息很明确：CKB 社区欢迎你来提升技能，并为此提供实际的方法和资金。无论你是经验丰富的开发者，还是刚刚起步，这里都有学习、尝试和留下自己印记的空间。CKB 的新篇章已经展开，等待社区主导书写。
