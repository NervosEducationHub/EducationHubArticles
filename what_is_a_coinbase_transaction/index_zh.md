一个区块通常包含许多交易，其中有一笔特殊交易与众不同：coinbase 交易（coinbase transaction）。这个术语经常引起混淆，因为许多人会联想到那家知名的加密货币交易所。实际上，是交易所借用了这个重要区块链概念的名称，而不是相反。

coinbase 交易并非由一个用户发送给另一个用户，也不会将任何已有的币作为输入来消耗。它由[矿工](https://www.nervos.org/knowledge-base/difference_between_miner_full_node)创建，是生成新币、奖励矿工付出劳动的机制。



## 理解 coinbase 交易

区块链是一串通过密码学哈希连接起来的区块，每个区块都包含一份交易列表。在比特币这类[工作量证明（proof-of-work）](https://www.nervos.org/knowledge-base/pow_vs_pos_unravelling)（PoW）区块链中，添加新区块的过程由挖矿驱动。挖矿成本高昂，需要专用的[挖矿硬件](https://www.nervos.org/knowledge-base/crypto_mining_hardware)、电力和运营支出。如果没有激励，矿工就没有理由维护网络安全，这正是区块奖励的作用。

coinbase 交易是一种特殊交易，作为每个区块的第一条交易，由成功将新区块添加到链上的矿工创建，用于发放区块奖励。区块奖励由新铸造的币，以及用户在交易中支付的交易费组成。

### **不同区块链和共识模型中的差异**

不同区块链实现 coinbase 交易的方式并不完全相同。比特币的设计是典型范例，但莱特币（Litecoin）和 [Common Knowledge Base](https://www.nervos.org/)（CKB）等其他工作量证明链采用类似模型，也存在细微差别，例如成熟期或奖励分配方式可能不同。

在权益证明（proof-of-stake，PoS）系统中，没有挖矿，因此也没有与求解难题相关联的传统 coinbase 交易。验证者（validators）通过铸币机制或费用再分配获得奖励。一些 PoS 链仍包含特殊的系统交易，用于发放验证者奖励或重新分配费用。即使链上不称其为 coinbase 交易，其功能也往往类似。

也存在混合系统。有些网络结合 PoW 和 PoS，形成独特的奖励机制，可能同时包含类似 coinbase 的交易和验证者奖励。



## coinbase 交易与普通交易有何不同

普通交易必须引用先前区块中的[未花费交易输出（UTXO，unspent transaction outputs）](https://www.nervos.org/knowledge-base/utxo_model_explained)，而 coinbase 交易没有输入。它遵循区块链的发行规则，凭空“创造”新币。

这一独特性质，使它成为比特币等加密货币进入流通的机制。如今存在的每一枚比特币，都可以追溯到某个区块中的 coinbase 交易。用户之间的交易则只是将已有的币在地址之间转移。coinbase 交易让货币供应量按照写入协议的计划增长。

任何有效区块都必须将 coinbase 交易放在第一位。这不仅是惯例，也是共识强制执行的规则。如果矿工试图将它插入区块的其他位置，其他节点就会拒绝。严格的位置要求确保了整个网络的一致性，避免对哪笔交易负责发放奖励产生歧义。

另一个主要区别是灵活性。coinbase 交易允许矿工在名为 coinbase 的字段中加入任意数据。历史上，矿工曾利用这一字段嵌入消息或标识符。例如，[中本聪（Satoshi Nakamoto）](https://en.wikipedia.org/wiki/Satoshi_Nakamoto)在比特币第一个区块的 coinbase 交易中写下了著名的一句话：“*泰晤士报 2009 年 1 月 3 日：财政大臣或将对银行实施二次救助*”。

coinbase 交易的特殊之处还在于，其输出受到成熟期的限制。例如，在比特币中，矿工不能立即花费 coinbase 交易产生的币，必须等待 100 个区块。这项保护措施防止矿工重组区块链并对奖励进行双重支付（double-spending）。

| **方面** | **coinbase 交易** | **普通交易** |
| ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **用途** | 创建新币并奖励矿工。 | 在用户之间转移已有价值。 |
| **创建方式** | 矿工找到新区块时创建。 | 任何希望发送加密货币的用户都可创建。 |
| **区块中的位置** | 始终是区块中的第一笔交易。 | 位于 coinbase 交易之后。 |
| **输入** | 一个空输入。 | 一个或多个输入，引用先前交易的未花费输出。 |
| **新币创建** | 生成新币。 | 转移已有的币。 |
| **对供应量的影响** | 增加加密货币总供应量。 | 不影响总供应量，只转移已有的币。 |
| **金额** | 区块补贴与交易费之和。 | 用户发送的金额，加上一笔交易费。 |
| **花费限制** | 受成熟期限制，例如比特币为 100 个区块。 | 在区块链上确认后即可花费。 |



## coinbase 交易在区块链网络中的重要性

coinbase 交易在区块链生态中承担几项关键功能：

- **矿工激励**：它为矿工向网络投入计算资源提供经济激励。没有这套奖励制度，矿工就缺乏参与高耗能网络安全维护过程的经济动力。

- **新币发行**：coinbase 交易是将比特币等新生成的原生币投入流通的机制。这种受控发行有助于维持加密货币的货币政策。

- **网络安全**：通过 coinbase 交易发放的区块奖励，补偿矿工验证交易，以及通过工作量证明共识维护区块链安全的工作。

- **交易费分配**：除区块补贴，即新创建的币外，coinbase 交易还将区块中所有交易的交易费汇集并分配给矿工。

- **可预测的货币政策**：预先确定的区块奖励计划，包括减半事件，使新币发行透明且可预测，这是比特币等加密货币价值主张的基础。



## 创建与验证的分步流程

创建并验证 coinbase 交易涉及几个步骤。

1. **准备区块**：矿工着手创建新区块时，从[内存池](https://www.nervos.org/knowledge-base/mempool_in_cryptocurrency)，即未确认交易池中，收集待处理交易，准备将它们加入新区块。
2. **创建 coinbase 交易**：矿工创建一笔没有输入的特殊交易，这就是 coinbase 交易。普通交易需要先前交易的输入，coinbase 交易则按照协议许可凭空生成新币。
3. **指定奖励**：矿工将自己的钱包地址指定为 coinbase 交易的输出，确保成功挖出区块后能收到奖励。如果需要在[矿池](https://www.nervos.org/knowledge-base/cryptocurrency_mining_pools)参与者之间分配奖励，矿工也可以指定多个地址。
4. **计算金额**：coinbase 交易的总金额等于当前区块补贴，例如比特币在 2025 年为 3.125 BTC，加上区块中所有交易的交易费总和。
5. **挖掘区块**：矿工将这笔 coinbase 交易作为新区块的第一笔交易，并开始求解挖出区块所需的复杂数学问题：不断改变 nonce 值，对区块头（block header）反复进行哈希计算，直到找到满足[难度目标值](https://www.nervos.org/knowledge-base/cryptocurrency_mining_difficulty)的哈希值。
6. **确认**：区块被成功挖出并加入区块链后，coinbase 交易就得到确认。但奖励通常还需要额外的确认，例如比特币需要 100 个区块，之后才能花费。

如果矿工没有领取全部区块奖励，一部分币就可能永久丢失。例如，比特币区块链[第 526,591 个区块](https://www.blockchain.com/explorer/blocks/btc/526591)的区块补贴总额为 12.5 BTC，但矿工在 coinbase 交易输出中只给自己分配了 6.25 BTC，导致 6.25 BTC 不可逆地损失。



## 结论

coinbase 交易是区块链网络中最容易被忽视、却又不可或缺的组成部分之一。它不仅是区块中的第一笔交易，也是每一枚币的诞生之处、货币政策的引擎，以及让矿工激励与网络安全保持一致的机制。没有它，比特币这样的工作量证明区块链就无法运行。

随着区块链发展，coinbase 交易的细节可能改变，但其目的不会变。它将继续成为去中心化加密货币的心脏，为每个新区块注入活力，确保这些数字经济持续繁荣。
