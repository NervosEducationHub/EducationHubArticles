闪电网络 URL（Lightning Network URL，LNURL）是 2019 至 2020 年间出现的一组开放协议标准，旨在简化闪电网络钱包与服务之间的交互。

它使用 URL 编码闪电支付参数，并通常以可扫描的二维码或可点击的链接呈现，将原本需要技术操作的流程转变为快速、直观、顺畅的体验。



## 闪电网络与闪电发票

闪电网络是比特币的 Layer 2 扩容方案，主要目的是让比特币交易更快、费用更低。将每笔小额交易直接记录到比特币区块链上，可能既慢又贵；闪电网络则允许通过[支付通道（payment channels）](https://www.nervos.org/knowledge-base/ultimate_guide_to_payment_channels)在链下完成支付。

支付通道就像两名参与者之间的一本私有账本。在通道内，比特币可以即时、反复转移，无需等待区块链确认。通道关闭后，只有最终余额会被记录到区块链上。这种结构让比特币能够用于日常活动，例如微支付、在线打赏和小额零售支付。

在闪电网络上，发送比特币并不像输入对方地址那么简单，还需要一份称为发票（invoice）的支付请求。闪电发票是一份独特的、经过编码的支付请求，会指定向谁付款、支付多少，有时还会说明用途。每张发票通常只能使用一次，而且会在短时间后过期。这正是 LNURL 希望改善的一个重要细节。



## LNURL：让闪电支付更简单

闪电发票的一次性特征会增加操作负担。每次支付都需要生成新发票，即使是小额或重复转账也不例外。例如，接受 1 美元打赏的内容创作者，每次有人付款时都需要生成一张新发票。对付款方和收款方而言，这个过程都很烦琐。

LNURL 是 Lightning Network URL 的缩写。它让钱包通过网页链接直接与服务通信，从而解决这一问题。这些链接可以放入二维码中，也可以作为可点击的 URL 分享。扫描或点击后，钱包会自动与服务交互，获取所有必要的支付信息，无需手动创建发票。

LNURL 将重复的技术操作变成流畅的自动化流程，让闪电支付更接近传统数字支付的便捷体验。

### LNURL 如何工作

LNURL 的核心是一个网页链接，可触发闪电钱包与服务器之间的一系列自动化交互。

例如，用户在咖啡馆用闪电钱包扫描 LNURL 二维码。钱包联系相应的服务器，从服务器获取支付请求，并向用户展示支付详情。用户确认交易后，支付便会自动完成。

请求、验证和确认等所有技术通信都在后台完成。整个体验因此更为简洁，无需手动复制或粘贴发票代码。

### LNURL 的主要类型

LNURL 不仅能用于付款，还包含面向不同任务的多个子协议：

- **LNURL-pay**：简化收款。商家或创作者可以展示一个静态二维码，支持多笔或重复交易，非常适合在线打赏、捐赠或重复购买。

- **LNURL-withdraw**：让用户自动从服务中提取资金，例如提取收益、处理退款或取出余额。

- **LNURL-auth / LNURL-login**：支持使用闪电钱包免密登录网站和应用。钱包充当一种安全的身份凭证，无需用户名或密码。



## LNURL 的优势

LNURL 隐藏了技术复杂性，带来类似现代电子支付的体验。对商家而言，它减少了结账环节的操作负担，并可能提高转化率。静态二维码可以印在菜单、海报上，或展示在网站上，让顾客即时完成支付，而不必每次都生成新发票。

LNURL 还能提高支付的可靠性。传统闪电支付可能因发票过期或金额不符而失败。LNURL 的交互流程会在发起支付前验证参数，确保双方对所有细节达成一致。LNURL 服务器还可以提供节点连接提示，优化支付路由，降低交易失败的概率，并可能减少路由费用。

除了简化支付，LNURL 还带来了新的商业模式。它支持面向内容创作者的微额打赏系统、订阅服务，甚至分期付款或周期性扣款等复杂支付流程。其中一个很有前景的方向是流式支付（streaming payments），让资金能够持续流动。支付可以按秒或按分钟进行，为按使用量付费的数字服务和实时报酬结算带来可能。



## 风险与注意事项

LNURL 提升了易用性，也带来了一些取舍。每个 LNURL 都依赖服务器响应钱包查询，因而可能形成故障点。如果服务器离线，支付就无法完成。被攻破或恶意的 LNURL 服务器可能提供虚假数据或将付款导向其他目的地，试图误导钱包。

隐私也是一个需要关注的问题。由于 LNURL 通过互联网通信，服务器可能记录 IP 地址或用户活动。此外，LNURL 的普及仍处于早期阶段。并非所有闪电钱包都支持完整的 LNURL 规范，因而用户体验并不一致。



## 结语

LNURL 是让比特币支付像其他数字交易一样轻松的重要一步。它以直观的链接和二维码取代复杂的发票，弥合了技术创新与实际易用性之间的差距。

随着比特币不断发展为全球金融网络，LNURL 等标准确保易用性跟上技术进步。LNURL 让闪电网络更容易使用，推动比特币最初的愿景走向现实：建立一个简单、快速、向所有人开放的点对点电子现金系统。
