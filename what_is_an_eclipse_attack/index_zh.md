区块链网络是由[节点](https://www.nervos.org/knowledge-base/difference_between_miner_full_node)组成的分布式系统。这些通过互联网连接的计算机相互通信，分享交易和区块信息。这种点对点（P2P）设计常被称赞，因为它让区块链更能抵御审查和攻击，但没有任何系统能完全免受威胁。

日蚀攻击（eclipse attack）就是其中一种威胁。它不直接攻击钱包，也不利用密码学的弱点，而是悄悄潜伏在 P2P 网络中，将单个节点与诚实网络隔离，向其提供误导信息。这种隐蔽却有力的干扰可能引发连锁反应，带来从双重支付到审查等更广泛的系统性风险。



## 理解日蚀攻击

在比特币、以太坊和许多其他区块链网络中，节点不依赖中央机构，而是组成点对点网络，每个节点只与有限数量的对等节点保持连接。这种连接限制意味着，节点永远无法直接了解其他所有参与者，而是依赖对等节点转发信息。例如，一笔交易创建后，会先广播给邻近节点，再由它们继续传递，直到整个网络都得知这笔交易。同样，矿工发现新区块后，该区块也必须在网络中传播，才能达成共识。

这种去中心化架构在许多方面很稳健，但也带来了弱点。如果攻击者能够操纵受害节点所连接的对等节点集合，就能控制哪些信息可以到达受害节点。这正是日蚀攻击的基础。

日蚀攻击是一种网络层攻击，恶意参与者垄断目标节点的全部连接，实际上将其与正常的区块链网络隔离。隔离后，受害节点只能看到攻击者控制的区块链版本。“日蚀”这个名称很贴切：正如日食时月球会挡住射向地球的阳光，攻击者的对等节点也会阻挡真实的区块链信息到达受害节点。

### **日蚀攻击与 51% 攻击**

[51% 攻击](https://www.nervos.org/knowledge-base/what_is_51_attack)需要控制[工作量证明（proof-of-work）](https://www.nervos.org/knowledge-base/pow_vs_pos_unravelling)区块链中超过 50% 的算力，也就是矿工用于解答密码学难题的计算能力；日蚀攻击则只需控制受害节点的连接。因此，日蚀攻击更节省资源，对规模较小的攻击者而言也可能更容易实施。

### **日蚀攻击与女巫攻击**

[女巫攻击（Sybil attack）](https://www.nervos.org/knowledge-base/sybil_attacks_consensus_mechanisms)通过创建大量虚假身份来压倒网络。日蚀攻击经常采用类似女巫攻击的策略，即部署大量虚假节点，但最终目标是有针对性地隔离节点，而不是影响全网。它更像精准打击，而非系统性的全面干扰。

### **日蚀攻击与分区攻击**

区块链分区攻击（partition attack）通常将区块链网络分为两个或更多彼此隔离的部分，阻止它们通信，导致区块链账本不一致、双重支付（double-spending）和[分叉](https://www.nervos.org/knowledge-base/what_is_a_hard_fork_soft_fork)。日蚀攻击则像针对个体的狙击，常被用作实施更大规模攻击的跳板。



## 日蚀攻击如何运作

节点通常维持一定数量的入站和出站连接。例如，Bitcoin Core 默认不会建立超过 8 个出站连接。攻击者的目标，就是用自己的恶意节点占满所有连接槽位。

日蚀攻击的步骤如下：

1. **准备**：攻击者部署大量恶意节点，有时多达数千个。这些节点分布在不同 IP 地址和子网中，以免轻易被发现。
2. **连接**：攻击者试图建立大量连接，使受害节点难以招架。当受害节点重启或刷新连接时，会在不知情的情况下，主要甚至完全连接到攻击者的节点。如果受害节点已有诚实的对等节点，攻击者可能采用驱逐策略，例如用畸形流量进行泛洪，迫使连接断开，再让自己的节点填补空缺。
3. **隔离**：一旦受害节点的连接被攻击者控制，它实际上就被切断了与真实网络的联系。攻击者通过不断刷新这些连接，并阻止任何诚实的对等节点接入，维持日蚀状态。
4. **操纵**：此时，攻击者决定受害节点能看到什么信息。他们可以延迟区块传播、隐藏某些交易，甚至向受害节点提供另一条区块链。从受害节点的角度看，一切似乎正常：区块不断到达，交易持续流动，网络看起来仍在运行。但所有这些数据都经过攻击者筛选和控制。

日蚀攻击可能持续几分钟，也可能持续几小时，取决于攻击者的目标。关键在于，在这段时间内，受害节点对真实情况一无所知。



## 日蚀攻击背后的动机

日蚀攻击会利用社会和经济激励：

- **双重支付**：攻击者可以隔离商家的节点，向其提供一笔虚假交易，再在真实网络中的其他地方花费同一笔币。商家不了解真实区块链的情况，便接受了这笔欺诈性付款。

- **自私挖矿（selfish mining）**：在挖矿场景中，隔离矿工让攻击者能够操纵区块传播。受害矿工可能浪费资源，在陈旧或无关的区块上挖矿，而攻击者则秘密地在最长链上继续工作。

- **审查与延迟**：攻击者可能阻止特定交易到达受害节点，或延迟某些区块的传播，实际上对信息实施审查。

- **策略优势**：在某些情况下，攻击者可能只是想干扰竞争对手、拖慢其他矿工，或破坏网络稳定性，以获得影响力。

这些动机表明，日蚀攻击并不总是为了立即窃取资金。在区块链经济复杂的博弈中，它们也可以成为策略工具。



## 日蚀攻击的后果

日蚀攻击的影响取决于目标和攻击者的目的。对普通用户而言，最直接的风险是接受无效交易或区块。对商家而言，可能意味着因双重支付而遭受经济损失。对矿工而言，则可能造成资源浪费和盈利能力下降。

从系统层面看，反复或大规模发生的日蚀攻击，可能侵蚀人们对区块链的信任。即使密码学基础仍然完好，用户也必须相信网络本身会公平地传播信息。如果这种信任受到破坏，区块链的采用程度和用户信心都可能下降。

在极端情况下，日蚀攻击可以成为更大规模攻击的跳板。例如，隔离足够多的矿工，可能为自私挖矿或链重组（chain reorganizations）创造条件，进而扰乱网络共识。

日蚀攻击还有不同变体。连接重置攻击（connection reset attack）可以不断干扰诚实的对等节点，确保攻击者占据主导地位。时间膨胀攻击（time dilation attacks）利用日蚀技术减慢区块向某个矿工的传播，在不易察觉的情况下降低其效率。在[闪电网络](https://en.wikipedia.org/wiki/Lightning_Network)或其他 Layer 2 协议中，日蚀攻击可被用来使[支付通道（payment channels）](https://www.nervos.org/knowledge-base/ultimate_guide_to_payment_channels)停滞或发生路由错误。



## 防御与缓解措施

没有完美的防御，但结合以下措施，可以提高实施日蚀攻击的成本和难度，降低其大规模实施的可行性。

- **对等节点多样性**：可以通过程序设计，让节点连接来自广泛 IP 地址和子网的对等节点，使攻击者更难垄断全部连接。

- **连接限制**：限制来自同一 IP 地址段的连接数量，降低恶意对等节点进行连接泛洪的风险。

- **对等节点轮换**：定期更换对等节点，确保攻击者无法无限期保持控制。

- **更强的对等节点选择算法**：仔细评估连接对象，并避开可疑模式，可以让节点更好地抵御攻击。

- **网络层防御**：防火墙、速率限制和可疑对等节点黑名单等工具，可以减少暴露风险。

如果怀疑遭遇日蚀攻击，补救通常从较大幅度的操作开始：重启节点、清空对等节点列表，或通过不同网络接口重新连接。运营者还可以轮换 IP 地址、增加出站连接槽位，或使用 VPN 和 Tor 使连接来源更加多样。

没有任何单一措施能保证安全。关键是纵深防御（defense in depth）：结合最佳实践、监控和风险意识，让攻击者即使短暂得手，也无法长期维持控制。



## 结语

日蚀攻击可能不像 51% 攻击那样经常登上头条，但它的隐蔽性使其危险程度毫不逊色。攻击者通过将节点与诚实网络隔离，获得了为受害者扭曲现实的能力。后果可能是盗窃、计算资源浪费、审查，或对整个系统的不信任。

过去十年，研究者和开发者不断加固协议、引入新的防御措施，并提高人们的风险意识。但只要区块链网络仍依赖连接数量有限的点对点架构，风险就无法彻底消除。保持警惕、确保多样性并持续研究，缺一不可。
