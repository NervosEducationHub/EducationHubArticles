以太坊作为领先的智能合约平台，长期面临可扩展性难题。Rollup 将交易处理从基础层转移出去，大幅降低成本，成为一种前景可期的解决方案。但在快速发展的加密世界中，解决问题的方案本身也终究需要改进。Based Rollup 由此登场，它试图让 Rollup 更贴近以太坊的长期愿景。

Based Rollup，也称 L1 排序 Rollup，是一种与以太坊基础层更深度融合的新型 Layer 2 方案，具体而言，它依靠以太坊区块提议者来处理排序。

这一看似微小的改变，对去中心化、安全性和收益分配的一致性有着重大影响。但要理解 Based Rollup 的特别之处，我们首先需要了解传统 Rollup 在以太坊生态中的作用。



## Rollup 在以太坊扩容计划中的作用

以太坊的设计重视安全和去中心化，但这些优先目标以牺牲速度和吞吐量为代价。随着网络发展，以太坊无法在链上承载需求的问题愈发明显。[Gas 费](https://www.nervos.org/knowledge-base/what_is_a_blockchain_gas_fee)飙升，交易变慢，用户开始寻找替代方案。

Rollup 的出现，是为了在不牺牲以太坊核心原则的前提下实现扩容。简单来说，Rollup 将大量交易打包并在链下处理，再将最终数据或证明提交回以太坊。这样既把繁重工作移出基础层，又保留了以太坊的安全模型。

Rollup 主要有两种：[乐观 Rollup](https://www.nervos.org/knowledge-base/what_are_optimistic_rollups_and_how_do_they_work) 和零知识（ZK）Rollup。

乐观 Rollup 默认交易有效，除非有人证明它无效；ZK Rollup 则事先使用密码学证明验证交易。两者都旨在降低成本和拥堵，但处理有效性与信任的方式不同。无论哪一种，Rollup 都需要决定纳入哪些交易，以及按什么顺序排列，这个过程称为排序（sequencing）。

传统 Rollup 一直自行运行排序器（sequencers）。排序器本质上是受信任的参与方或系统，在交易最终确定于以太坊之前，决定其先后顺序。这种方式虽能运作，却引入了中心化风险，还形成了一个位于以太坊自身激励体系之外的经济层。Based Rollup 则彻底改变了这一模式。



## 什么让 Rollup 成为“Based” Rollup？

Based Rollup 中的“based”，指从根本上立足于以太坊本身。更具体地说，Based Rollup 使用以太坊的区块提议者，作为 Layer 2 交易的排序器。这与通常指定独立参与方或机制来处理排序的传统 Rollup 有很大不同。

在 Based Rollup 中，在 Layer 1 提议区块的以太坊验证者，同时也为 Rollup 选择交易顺序。换句话说，Rollup 将排序功能外包给以太坊基础层。这种紧密集成，能够显著改变 Layer 1 与 Layer 2 之间的经济和安全关系。

从设计角度看，Based Rollup 顺应了以太坊自身的路线图。随着以太坊转向[提议者与构建者分离（proposer-builder separation，PBS）](https://www.nervos.org/knowledge-base/What_is_Proposer_Builder_Separation%20_in_Ethereum)及其他缓解 MEV 的策略，Based Rollup 希望与这些变化保持一致，而不是绕开它们。它们以以太坊作为排序和交易收录的基础，而不是在以太坊之上再建立一个可能中心化的经济控制层。这种一致性有着深远影响，既有正面，也有负面。



## 排序为何重要：权力与利润

排序不只是技术细节，更是一种权力。控制交易排序的人，可以影响谁的交易被纳入、按什么顺序纳入，以及付出多少成本。这种控制具有真实的经济价值，尤其是考虑到[最大可提取价值（MEV）](https://ethereum.org/en/developers/docs/mev/)时：排序器可以通过对自己有利的交易重排、插入或排除来获利。

在传统 Rollup 中，排序功能往往由项目自身掌握，或交给少数参与者。这使这些参与者对 Rollup 生态拥有过大的权力，也创造了一个独立于以太坊验证者的新经济孤岛。虽然实践中可能有效，却引出了公平性、去中心化和长期激励方面的问题。

Based Rollup 试图将排序角色交回以太坊基础层来解决这一问题。它们不把控制权赋予新的参与方，而是让以太坊提议者将排序作为正常出块职责的一部分。这样，权力和利润都留在以太坊既有验证者集合中，也避免了重复建立激励结构。

这也涉及监管层面：将 Rollup 排序留在以太坊内部，能够减少为 Layer 2 运营单独建立治理结构、代币体系或合规策略的需要。这可能让 Based Rollup 更精简、更透明，也更符合以太坊的理念。



## 提议者与构建者分离（PBS）的作用

Based Rollup 的核心动机之一，是以太坊即将到来的提议者与构建者分离（PBS）升级。

PBS 是一项拟议的以太坊升级，将区块生产工作拆成两个角色：构建者（builders）组装区块，并将区块提供给每个时隙的提议者；提议者（proposers）看不到区块内容，只选择最有利可图的一个，向区块构建者支付费用，再将区块发送给对等节点。

PBS 旨在对抗 MEV 中心化，改善全网公平性。Based Rollup 的设计与这一未来方向协调一致。通过让以太坊提议者处理 Rollup 排序，它们实际上形成了另一种构建者与客户端的关系。Rollup 用户向以太坊提议者提交交易，由后者按适当顺序将其纳入区块。

这一模式受益于 PBS 带来的透明度和竞争。排序逻辑不再由单一实体掌握，多个构建者可以竞争，以最高效或最公平的方式纳入 Rollup 交易。这会自然形成改善执行效果的激励，而不会将生态割裂成彼此孤立的 Rollup 经济体。



## 经济利益的一致性与价值获取

Based Rollup 的另一个主要优势，是协调 Layer 1 与 Layer 2 之间的经济价值。在传统 Rollup 中，用户支付的费用往往流向 Rollup 排序器或运营者，而非以太坊验证者。这造成了脱节：以太坊提供安全性和数据可用性（data availability），却无法直接从 Rollup 使用产生的费用中受益。

Based Rollup 通过让以太坊提议者负责交易排序，改变了这一关系。这意味着 Rollup 上支付的费用，最终由以太坊验证者获取，从而增强以太坊的长期经济安全性。

这也降低了 Layer 2 在经济或政治层面与 Layer 1 对立的风险。如果 Rollup 创造大量价值却全部留给自己，最终可能试图尽量减少对以太坊的依赖，甚至彻底分叉离开。Based Rollup 则在经济和结构上都与以太坊的成功紧密相连。这种一致性未必能解决每个治理问题，却能降低生态割裂或价值流失的可能性。



## Based Rollup 的风险与取舍

Based Rollup 虽有诸多好处，也需要作出取舍。主要问题之一是延迟。排序与以太坊出块绑定，意味着 Based Rollup 继承了 Layer 1 的时间节奏。与拥有高速独立排序器的 Rollup 相比，用户可能要等待更久，交易才会被纳入。

灵活性也是问题。传统 Rollup 可以微调排序逻辑，以支持快速最终性、高频交易或定制排序等需求。Based Rollup 将排序交给以太坊，也就放弃了部分自主权。这可能降低其对需要特定性能保障的专业应用的吸引力。

安全性同样需要考虑。Based Rollup 受益于以太坊验证者集合，却也将更多责任集中到提议者身上。如果提议者被收买、串通或审查交易，可能以难以预测的方式影响 Rollup 行为。PBS 等机制旨在缓解这一问题，但仍在开发中，尚未经受充分的实战检验。

最后还有推广采用的挑战。Based Rollup 代表了一种理念转变。说服开发者和项目放弃排序控制权，可能很困难，尤其是它们已经能从现有模式中获利时。Based Rollup 要求团队更深地信任以太坊基础层，这未必对所有人都有吸引力。



## Based Rollup 的应用场景与未来展望

尽管面临挑战，Based Rollup 仍有前景可期的应用。对于希望获得强大去中心化保障、又不想管理自身排序器逻辑的 DeFi 协议，它们可以作为公共基础设施。对 DAO 等高度重视治理的系统而言，它们也可能有吸引力，因为这类系统尤其看重交易排序的透明度与中立性。

随着以太坊继续演进，尤其是 [Danksharding](https://ethereum.org/en/roadmap/danksharding/) 和无状态客户端等升级推进，Based Rollup 可能变得更高效、更具吸引力。Rollup 与以太坊共享的发展路线，可以降低成本、简化集成，并在不同层之间提供更连贯的用户体验。

未来，我们可能看到兼顾两者优势的混合模式。一些项目短期内可能以传统 Rollup 运行，同时规划在基础设施成熟后迁移到 Based Rollup；另一些可能采用模块化方式，让用户根据需求，在快速排序和基于以太坊的排序之间选择。

归根结底，Based Rollup 反映了区块链中更广泛的一种趋势：将权力与价值交还给技术栈中最去中心化、最安全的部分。通过让 Layer 2 系统更紧密地锚定于以太坊，它们可能帮助去中心化应用构建更可持续、更统一的未来。



## 结语：新的一层信任

那么，什么是 Based Rollup？它是一种将排序权从独立运营者转移给以太坊自身区块提议者的新型 Layer 2。这不仅是技术变化，也是理念变化：它相信，以太坊的安全性、透明度和经济激励，应延伸到建立在其上的扩容层。

Based Rollup 并非适合所有场景，却为下一代 Rollup 设计提供了有吸引力的愿景。它简化基础设施、改善利益一致性，让以太坊生态在增长中保持凝聚力。在加密世界寻找更好扩容方案的过程中，Based Rollup 的突出之处不仅在于解决什么问题，还在于如何解决：信任基础层，并以此为基础继续构建。
